# 超级管理员工作台演示

超级管理员登录后进入 `/workbench` 查看。首页使用 ECharts 显示产品交付进度、库存与缺口、成品出入库趋势、客户 TOP 20；点击图形或明细按钮可查看型号、客户订单和风险订单。其他角色保留原工作台占位内容。

当前使用独立的演示数据，不与销售订单等页面的真实/现有 mock 数据混用。页面标注「演示数据」，仅展示，不写入业务库。

## 真实数据接入

- `mocks/data/workbench.ts`：演示明细生成器，使用同一组订单与流水计算各项指标。
- `src/pages/workbench/useWorkbenchData.ts`：唯一演示数据接入点。接入真实后端时移除演示生成器，替换为业务 API / React Query 查询，处理加载、失败和空状态，同时移除页面演示标识。
- `src/data/workbench.ts`：独立读模型 `WorkbenchData` 与纯聚合函数。适配字段：产品 BOM 编码、品类、型号、规格、单位、当前库存；订单号、客户编码、下单日、交期、订单数量、累计已发、取消状态；按业务日期记录的有效入库、出库数量。

如后端提供分页明细，不可仅用当前页计算经营指标。应新增受超级管理员权限保护的聚合接口，按仓库全部数据计算，并同步 `src/api/types.ts`、`mocks/request/`、`docs/api/openapi.yaml`。此次演示没有新增或修改 HTTP 接口。

## 口径

- 订单筛选按下单日，已发数量为所选订单截至今日的累计交付。需求总量 = 已发 + 未发，含已完成订单；取消订单仅保留已履行数量。
- 当前库存、缺口、风险不受订单周期影响。先按每个 BOM 求缺口，再汇总品类；同品类不同规格库存不可互抵。
- 风险按交期及订单号依次分配共享库存，提醒全部逾期未发完订单，以及今天至未来 7 天到期且缺货的订单。
- 趋势使用独立周期，按业务日期汇总；排除作废流水，不把库存调整作为生产入库。超过 90 天按月汇总。
- 客户按编码合并；完全取消且未履行的订单不计下单笔数，部分履行后取消计一笔并保留已履行数量。
- 当前演示统一单位为「个」。真实数据若有不同单位，必须分组统计与展示，不可直接相加。
- 出库数据表示系统登记口径，未发不等于未生产；页面不宣称能够追踪线下生产过程。
