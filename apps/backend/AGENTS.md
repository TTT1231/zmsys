# AGENTS.md

## 命令

| 用途       | 命令             |
| ---------- | ---------------- |
| 构建       | `pnpm build`     |
| 格式化     | `pnpm format`    |
| 启动       | `pnpm start`     |
| lint检查   | `pnpm lint`      |
| 类型检查   | `pnpm typecheck` |
| 测试       | `pnpm test`      |
| 测试覆盖率 | `pnpm test:cov`  |
| E2E 测试   | `pnpm test:e2e`  |
