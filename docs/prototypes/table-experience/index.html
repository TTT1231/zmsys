这版可以这样试

  1. 调整 BOM 列：拖动表头右边界，整列高亮，其他列保持原来的宽度。也可以用键盘左右键。
  2. 点“显示设置”：选择信息密度、显示列和宽窄，无需输入尺寸。
  3. 点 BOM 编码：侧边打开完整规格与物料，关闭后仍在原来的位置。
  4. 切换手机预览：体验入库、出库、订单的记录卡片、搜索、筛选和详情。
